# AI Course Recommendation System

## Description
The AI Course Recommendation System is a web-based application that recommends courses based on users' interests and preferences. It compares the user's selected interests with predefined course categories and displays suitable course recommendations.

## Objective
To develop a simple recommendation system that suggests relevant courses based on user preferences and demonstrates recommendation logic, pattern matching, and similarity-based ranking.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Enter the user's name.
- Select preferred topics and interests.
- Compare user interests with available course categories.
- Calculate course matching scores.
- Display recommended courses with matching percentages.
- Sort courses based on their matching scores.

## Working
1. The user opens the application in a web browser.
2. The user enters their name and selects interests such as Python, Artificial Intelligence, Machine Learning, Web Development, and Data Science.
3. JavaScript collects the selected interests.
4. The system compares the interests with predefined course tags.
5. A matching score is calculated for each course.
6. The courses are sorted according to their matching scores.
7. The recommended courses and their matching percentages are displayed.

## How to Run
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or directly in a web browser.
4. Enter your name and select your interests.
5. Click the recommendation button to view the results.

## Recommendation Logic
The system compares the user's selected interests with predefined tags for each course. Courses with more matching interests receive higher matching scores and are displayed as recommendations.

## Project Type
Rule-based recommendation system.

The project demonstrates how user preferences can be used to recommend relevant courses through a simple web application.
